# Phase 9 Results: SMK2 Bloom (multi-pass pyramid glow)

Resolve Studio 21.1.0.14, Windows. Project `SMK Phase9` (your `SMK Test` was not touched). Scripting only, no UI automation. One comp per check (named after it), each with a Note, explicit node positions (Note y −3; Background x 0; source x 4; effect x 8–10; Merge x 12–14; MediaOut at the right; one row per instance), `FlowView.Select()` before every paste, comp rate = timeline rate, Background +0.001 before every timed render, `SaveProject()` after each section. Comps are 24 fps, 120 frames, 1080p unless the name says otherwise. Measurements are PNG renders analysed with PIL (frame 40 unless stated; the Shape source is empty on frame 0 and the last frames and was not used there). Setup: `git pull`, `python scripts/install.py`, Resolve restarted, `python build/build.py`, every `tests/test_*.py` run once: all passed (**kernel-parity tests SKIPPED: no C compiler on this machine**; the GPU output was measured in Resolve).

## Change made in this phase

**`src/fuses/SMK2_Bloom.lua`, `src/core/smk_bloom.lua`: the halo stopped growing above about R = 120 and did not scale with the resolution (B2, B7).** With 6 pyramid levels the coarsest texel is 64 px, so the sum of levels saturates: R = 300 at 1080p looked like R = 120 (blue excess at 10 / 30 / 60 / 100 px: 35 / 13 / 1 / 1 against 38 / 10 / 2 / 1), and at 4K a 120 px@1920 radius (240 px) was drawn with the same pixel size as at 1080p (halo extent / width 0.0198 against 0.0385; 4K downscaled vs 1080p mean difference 0.130 /255). Fix: `sh = clamp(ceil(log2(R_px / 128)), 0, 3)` extra halvings are built first (up to 9 intermediates) and the 6 coarsest are composited (scale `2^(k+sh)`); new parameter `sh`, arrays `lw[9]` / `lh[9]`; radii up to 128 px (the default) are unchanged. After: R = 300 → 48 / 23 / 9 / 5 at 10 / 30 / 60 / 100 px; 4K vs 1080p mean difference 0.013, halo extent / width 0.0339 at both. `tests/test_bloom.py`: init order updated and one check added (24 pass). The composite pass still takes 7 input textures, as before.
