## Things to know

- **Cost (W14) is the main miss against the S9 target.** 75 ms for 12 letters and 240 ms for 40 means 40 letters cannot play at 24 fps in real time on this machine, in render time at least.
- The default Letter Count is 12. For other text lengths it must be set by hand, or the last letters do not finish their Out (W9). Auto-count is deferred, as the gate notes.
- Word and Line macros fade per character (W4 caveat).
- My UI automation moved focus away from Resolve during W15 and selected some text in your browser window (no edit was made); I stopped using UI automation after that.
