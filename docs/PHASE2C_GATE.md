# Phase 2c Gate — SMK2 UI Block v2 (first product preset)

Product = preset over core nodes: **Shape → Merge ← Label (Text+) → Animator** (4 nodes, 2 Fuses, ≈4 short wiring links, no expression web).
Generated by `build/make_macros.py` → `dist/templates/SMK2_UIBlock.setting`, installed to `Fusion/Macros/SMK2/` by `scripts/install.py`.
The macro is generated, not hand-drawn in Resolve, so **its Fusion-side loading is the main unknown**.

|---|---|---|
