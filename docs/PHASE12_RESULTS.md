# Phase 12 Results: hardening (H1–H15)

Resolve Studio 21.1.0.14, Windows 11. Project `SMK Phase12` (`SMK Test` not touched). Scripting only, no UI automation. One comp per check named after it (`H1_<product>`, `H2_*`, `H3_*`, …), distinct node positions, a Note per comp, `FlowView.Select()` before every paste, comp rate = timeline rate except where a check changes it, Background +0.001 before timed renders, `SaveProject()` after each section. Frames are 1080p unless stated; analysis by PIL on rendered PNGs (non-background pixel counts at step 4, threshold 6; pixel diffs).

**No source file under `src/` or `build/` was changed in this phase.** Setup: `git pull`, `python scripts/install.py`, Resolve restarted, `python build/build.py`, every `tests/test_*.py` run once (log: `docs/phase12_evidence/p12_tests.log`): **all pass** (macros 352, shape 47, text expressions 62, smk_core 49, look 35, pagecurl 31, … 0 failures); kernel-parity tests **SKIPPED (no C compiler)**. The `GPU failed … RunSession failed` lines in that log come from the offline test harness (no GPU there), not from Resolve.

## Findings that need your attention
0. **One Resolve crash (H15, 18:05:45)** during concurrent two-session use; not reproduced alone. See table.
1. **H5 — SMK Fuses blank in a comp on a trimmed timeline clip** (RenderEnd reads 0 there). Unresolved. This is the one genuinely open defect. Exact steps are in the table.
2. **Cost:** every macro is > 5 ms/frame at 1080p warm; CardStack is 23.5 ms warm and ≈ 3× that on its first (cold) render; Motion +8 ms (it forces Text+ re-rendering); at 4K Callout, ClickDemo, CardStack cost +47…+70 ms. Details and per-instance numbers: `PERFORMANCE.md`.
3. **Relief** at extreme parameters is blocky with a faint tiling pattern (H8). Cosmetic, not fixed.
4. **Late start 90000 (H4)** could not be tested at all in Resolve by scripting; not an SMK verdict.
5. **Harness note:** Resolve's Python script threads stalled repeatedly during the long benchmarks, and a second Claude session shared the Resolve instance for about 50 minutes; affected values are marked in `PERFORMANCE.md`.

## NOT VERIFIED
- Alpha-sum table for H1; 36 000-frame clip and late start 90000 (H4); H5 on a video clip / user-trimmed clip; H6 mp4 decode; per-scenario memory (H10); GPU time without PNG encoding (H9); Fusion console text (H15); kernel parity (no C compiler); `_Glass/_Neon/_Soft` costs.
