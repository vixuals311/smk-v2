### F3: every change to `build/make_macros.py` (re-run with `python build/make_macros.py`; `python scripts/install.py` installs)

1. New block after `COLOR`: `WEIGHT_ITEMS` (Light, Regular, Medium, SemiBold, Bold, ExtraBold, Italic, Bold Italic), `WEIGHT_DEFAULT = 4` (Bold), `FOUR_STYLE_FAMILIES` (Arial, Times New Roman, Verdana, Georgia, Consolas, Comic Sans MS, Segoe UI, Tahoma, Calibri, Cambria, Courier New, Trebuchet MS), and `style_expr(weight_ref, font_ref)`, which returns a 610-character Lua expression: Open Sans uses the style as chosen; the four-style families map Light/Regular/Medium to Regular, SemiBold/Bold/ExtraBold to Bold, and keep Italic and Bold Italic; any other font gets "Regular".
2. Text macros (`SMK2_TextLetter`, `SMK2_TextWord`, `SMK2_TextLine`): `TEXT_USER` gets a `Weight` combo (page Text, default Bold) and `TEXT_LABELS["Weight"] = "Weight"`; the `UIT_Text` node loses its fixed `Style="Bold"` and gets the expression `Style = style_expr("UIT_Ctrl.Weight", "UIT_Text.Font.Value")` (it reads its own Font input, another input of the same tool); `Weight` is published on the Text page right after Font (and excluded from the generic loop that publishes the other holder controls).
3. `SMK2_UIBlock`: a new holder node `UIB_Ctrl` (a Background at (0, 132), unconnected) with a `Weight` combo on the Card page; `UIB_Label` loses its fixed `Style="Bold"` and gets `Style = style_expr("UIB_Ctrl.Weight", "UIB_Label.Font.Value")`; `Weight` is published on the Card page between Font and Text Size. (The published key is `Ctrl_Weight`.)
4. `tests/test_macros.py`: the acyclic-graph check now ignores a tool reading its own other input (the Style expression reading Font; it works in Resolve), and the 90-character expression limit now allows up to 2,300 characters for the UI Block as well as the text macros. Result: macro tests 96 passed, 0 failed; text expression tests 62 passed, 0 failed.

Default look is unchanged: Weight defaults to Bold, so Open Sans Bold as before.
