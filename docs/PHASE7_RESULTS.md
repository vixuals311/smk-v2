# Phase 7 Results: SMK2 Connector and SMK2 Look

Resolve Studio 21.1.0.14, Windows. Projects `SMK Phase7 Connector` (section A) and `SMK Phase7 Look` (section B); your `SMK Test` was not touched. Scripting only, no UI automation. One comp per check, named after it, each with a Note, explicit node positions (Note y −3; Background x 0; source x 4; Look x 8 in section B; Merge; MediaOut at the right; one row per instance), `FlowView.Select()` before every paste, Background changed by 0.001 before every timed render, comp frame rate set to the timeline rate, `SaveProject()`. Comps are 24 fps and 120 frames unless the name says otherwise. Measurements are PNG renders analysed with PIL (frame 40 unless stated).

## Changes made in this phase

1. **`src/fuses/SMK2_Connector.lua`, `src/core/smk_connector.lua`: the start mark no longer stays on the last frame.** K1 showed 69 ink pixels on frames 118 and 119 (the start dot never left, so the clip's last frame was not empty). New parameter `visA` (start-mark visibility, fades to 0 over the last 8 % of the Out) and the path coverage is multiplied by `min(trim × 50, 1)` so a fully un-drawn line paints nothing. After the change every engine has 0 ink pixels on the last frame (K7). Frames 40 of K2, K4 and K5 re-rendered pixel-identical (max difference 0).
2. **`src/fuses/SMK2_Look.lua`: glow and outline were hard-cut at the input image bounds (M8, small images).** The output image now gets `IMG_DataWindow = ImgRectI(dw.left − pad, dw.bottom − pad, dw.right + pad, dw.top + pad)` with `pad = ceil(GlowRadius·px + OutlineWidth·px) + 2` (zero when glow and outline are off). The kernel gets `off[2]` / `osize[2]` (window origin and size) and treats samples outside the source as transparent instead of clamping to the edge. Shine and gradient only act where the input has alpha, so they need no padding. Full-canvas comps M2, M3, M4 and M8 re-rendered **pixel-identical** to before.
3. `tests/test_look.py`: new checks for the padded window and kernel origin/size, mock extended (29 pass). `python build/build.py` runs clean. Tests: `test_connector*.py` 23 + 32 pass, `test_look.py` 29 pass. **Kernel parity tests are SKIPPED (no C compiler on this machine)**, so the CPU reference and the GPU kernel of the two edited Fuses were not compared pixel by pixel in the test suite; the GPU output itself was measured in Resolve.
